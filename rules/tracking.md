# Tracking — Evidence-Based Skill Levels

- Never record a skill level or progress percentage from an unverified claim —
  including the user's own "I'm a 7 now"
- Levels change only on verifiable evidence: completed+verified phase project,
  in-session review with `file:line`, or a verified milestone
- Record the evidence with every update; no evidence, no change
- HTML 7/10 is the sole grandfathered baseline (65+ project artifacts);
  Frontend opens at 20% in `progress-tracking.md`
- Cap: max +2 per skill per week
- Update via `/progress` only — it keeps `skill-tree.md` and
  `progress-tracking.md` in sync
