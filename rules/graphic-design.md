# Graphic Design — Visual Execution Rules

When working with visual design, load the `design-system` skill for tokens and `ui-ux-expert` for UX patterns.

## Design before code

- Define color palette, typography, and spacing before writing any HTML/CSS
- Use a consistent design system — never mix ad-hoc values
- Check if the project already has tokens, theme files, or a style guide
