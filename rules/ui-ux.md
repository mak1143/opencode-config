# UI/UX — Interface and Experience Rules

When building interfaces, load the `ui-ux-expert` skill for design intelligence and the `design-system` skill for tokens.

## User-first thinking

- Every screen must answer: "What is the user trying to do right now?"
- Minimize cognitive load — show only what's needed at each step
- Reduce clicks/taps to reach the primary action
- Follow platform conventions (web, mobile, desktop) — don't reinvent
