Audit the specified code for security vulnerabilities. Cover all of the following:

## Checks
- **Vulnerabilities** — OWASP Top 10, injection, XSS, CSRF, auth flaws
- **Secrets** — API keys, tokens, passwords, private keys committed to code
- **Input validation** — sanitization, type coercion, boundary checks
- **Threat model** — attack vectors, privilege escalation, data exposure
- **Hardening** — least privilege, secure defaults, defense in depth
- **Dependencies** — known CVEs, outdated packages
