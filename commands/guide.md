Guide me toward the target, adapting to whichever mode fits best:

## Workflow
Create a complete workflow for the specified process. Define each step, input/output, error handling, and success criteria. Output as documented steps or a runnable pipeline.

## Roadmap
Build a milestone-based roadmap. Each milestone should be shippable and independently valuable. Include estimated effort per milestone and ordering dependencies.

## Teach
Explain the concept step by step. Start with the core idea, build up progressively, and check understanding along the way. Use analogies and concrete examples.

## Coach
Guide me toward the solution without giving it away. Ask probing questions, point me to relevant documentation or patterns, and help me discover the answer myself.
